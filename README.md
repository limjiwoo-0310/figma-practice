## 4. 주요 기능

- 마감 D-Day 상태 배지 자동 표시: 현재 시각과 신청 기간을 비교해 예정 / 진행중 D-n / 마감임박 D-0 / 종료 배지를 자동으로 붙입니다. 마감 시각은 "18:00 마감"처럼 괄호 없이 따로 적습니다.

- 장학금 신청 / 학자금대출 탭 전환 카드: 탭마다 카드 목록이 다르고, 보여줄 카드가 없으면 안내 문구가 나옵니다
- 주요 일정 캘린더, 검색창, 인기 메뉴

## 5. 트러블슈팅

이슈 1: 모바일↔데스크탑 전환 시 버튼·공지 목록 정렬이 어긋남
- 문제: 이전/다음 버튼과 공지 목록이 모바일→데스크탑으로 바뀔 때 정렬이 맞지 않고 여백이 사라짐
- 원인
버튼: 화살표와 글자를 gap과 한쪽 padding으로만 배치해서, 버튼 너비가 바뀌면 글자가 가운데에서 밀려남
공지 목록: 데스크탑에서 width: var(--size-notice-list)로 고정 너비를 줘서 부모 영역과 폭이 맞지 않음
- 해결
모바일은 화살표를 position: absolute로 버튼 끝에 고정하고, 좌우 여백을 같은 값으로 줘서 글자를 가운데 정렬
데스크탑은 Figma대로 화살표와 글자를 한 묶음으로 가운데 배치, 공지 목록은 width: 100%로 바꿔 부모 너비를 따르게 함


이슈 2: 공지사항 탭을 바꿔도 같은 글 목록이 보임
- 문제: 공지사항 / 홍보영상 / 재단동정 / 보도자료 탭을 눌러도 목록 내용이 그대로임
- 원인: 공지 데이터가 하나의 배열이라 어떤 탭을 골라도 같은 목록을 그림
- 해결: 데이터를 { 탭이름: [글 목록] } 형태로 바꾸고, NoticeBox가 notices[activeTab]만 보여 주도록 수정 (데이터가 없으면 빈 배열로 처리)


## 6. AI 활용 방식

- **맡긴 일**: Figma 내에 있는 베리어블을 활용한 디자인 시스템 정리 및 화면 구현
- **핵심 프롬프트**:
- "베리어블의 내용을 이용해서 디자인 시스템 파일 만들어줘."
- 이 Figma 노드를 보고 컴포넌트로 만들어줘. 색상·간격은 tokens.css 변수를 써줘.
- 모바일에서 데스크탑으로 바꾸면 버튼 글자가 가운데에서 밀려. Figma처럼 맞춰줘.

## 7. 회고

- **배운 점**: uiux와 바이브 코딩 분야에서의 ai 활용 방법을 배울 수 있었다. 단순히 모든 걸 맡기는 것이 아닌, AI를 활용해 나의 능력을 극대화 할 수 있다는 점을 배웠다.
- **아쉬운 점**: 완성을 하기 위해 기능을 하나하나를 뜯어보지 못한 점이 아쉽게 다가온다. 이는 추후에 개인 시간을 할애하여 코드를 살펴볼 것이다.
