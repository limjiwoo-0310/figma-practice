## 2. 프로젝트 정보

- **제작 기간**: 2026.11.06 ~ 2026.11.10 (4일)
- **담당 역할**: 개인 프로젝트 (기여도 100%)
- **담당 범위**: Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: 컴퍼넌트를 이용해 수월한 작업을 위해서 사용
- **GitHub Pages**: 무료 배포
- **Figma**: 개선 디자인
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- 주요 일정 카드 히어로 섹션에 배치
- 모바일·데스크탑 반응형 레이아웃
- 마감기한을 명시하는 뱃지 배치

## 5. 트러블슈팅

### 이슈 1: 컴퍼넌트 제작 과정에서 빠진 부분이 존재

- **문제**: 버튼과 정보 란이 모바일→데스크탑으로 변경 시 정렬이 맞지 않고 여백이 사라지는 오류가 발생함
- **원인**: 화면 비율에 따라 width값과 여백 값이 달라져야 하는데 해당 사항이 적용되지 않음
- **해결**: 해당 컴퍼넌트로 들어가 여백과 width값을 수정 후 정렬 확인→문제 해결

## 6. AI 활용 방식

- **맡긴 일**: Figma 내에 있는 베리어블을 활용한 디자인 시스템 정리 및 화면 구현
- **핵심 프롬프트**: 베리어블의 내용을 이용해서 디자인 시스템 파일 만들어줘.

## 7. 회고

- **배운 점**: uiux와 바이브 코딩 분야에서의 ai 활용 방법을 배울 수 있었다. 단순히 모든 걸 맡기는 것이 아닌, AI를 활용해 나의 능력을 극대화 할 수 있다는 점을 배웠다.
- **아쉬운 점**: 완성을 하기 위해 기능을 하나하나를 뜯어보지 못한 점이 아쉽게 다가온다. 이는 추후에 개인 시간을 할애하여 코드를 살펴볼 것이다.
