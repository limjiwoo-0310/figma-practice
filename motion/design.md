# 홍보 모션 영상 디자인 기준

- 장면, 사용 화면, 분리 요소, 예시 날짜는 `motion/아이디어.md`를 따른다. 이 문서는 **영상을 어떻게 보이게 하고 움직일지**를 정한다.
- 색, 글꼴, 라운드, 그림자는 `src/styles/tokens.css`(Figma에서 가져온 디자인 토큰)를 그대로 쓴다. 영상에서만 새로 정한 값은 **[영상 전용]**으로 표시했다.
- 수치 중 **제안** 표시는 제가 정한 기본값이다. 바꾸고 싶으면 이 문서만 고치면 된다.

## 1. 영상 기본 규격

| 항목 | 값 | 비고 |
|---|---|---|
| 화면 비율 / 크기 | 16:9, 1920 × 1080px | 제안. 모바일과 PC를 한 화면에 함께 담기 좋은 비율 |
| 초당 프레임 | 30fps | 제안 |
| 전체 길이 | 약 45초 | 제안. 장면별 시간은 아래 4번 표 |
| 소리 | 배경음악 + 효과음(버튼 눌림, 체크) | 제안. 음원은 저작권 확인 필요 |
| 자막 | 한국어. 모든 장면에 핵심 문장 1줄 | 소리 없이 봐도 이해되게 |
| 예시 표시 | 화면 오른쪽 아래에 `예시 화면` 문구를 계속 표시 | 일정 값이 실제가 아니기 때문 (`아이디어.md` 2번) |

## 2. 색

| 쓰임 | 토큰 | 값 |
|---|---|---|
| 기본 배경 | `--color-bg-page` | `#ECECEC` |
| 밝은 파란 배경 (강조 장면) | `--color-bg-colored` | `#F0FAFF` |
| 메인 색 (버튼, 강조선, 진행 단계) | `--color-primary` | `#0073B3` |
| 메인 색 진하게 (눌림 상태) | `--color-primary-hover` | `#005A8C` |
| 엔딩 배경 | `--color-b-900` | `#003959` |
| 마감 강조 (D-Day 배지) | `--color-point` | `#CC3802` |
| 제목 글자 | `--color-text-title` | `#1D1D1D` |
| 본문 글자 | `--color-text-body` | `#3E3E3E` |
| 팝업 뒤 어두운 배경 | `--color-dim` | 검정 50% |

- 마감 강조는 빨간색만 쓰지 않는다. **굵은 글씨 + 배지 배경 + 살짝 커지는 움직임**을 함께 쓴다. (PRD: 색상만으로 강조하지 않기)

## 3. 글꼴

- 글꼴은 **Pretendard GOV** 하나만 쓴다. 파일은 `src/fonts/` (Regular, Medium, Bold)
- 1920 × 1080 영상 기준 크기 **[영상 전용]**

| 쓰임 | 굵기 | 크기 | 비고 |
|---|---|---|---|
| 장면 핵심 문장 (큰 제목) | Bold | 72px | 한 줄 최대 18자 |
| 보조 문장 | Medium | 40px | |
| 자막 | Medium | 36px | 화면 아래 가운데, 아래 여백 80px |
| 강조 숫자 (D-DAY, 18:00) | Bold | 120px | `--color-point` |
| 예시 화면 표시 | Regular | 20px | 투명도 60% |

- 예외 조건은 괄호로 쓰지 않고 줄을 나눈다. (PRD 규칙)
  - 나쁜 예: `09:00~24:00 (단, 마감 당일은 18:00까지)`
  - 좋은 예: `신청 시간 09:00~24:00` / `마감 당일은 18:00까지`

## 4. 장면별 구성과 시간

`아이디어.md`의 장면 번호를 그대로 쓴다. 화면이 **없음**인 장면은 아래처럼 처리했다.

| 2 | 메인 D-Day 배지 | 0:04–0:09 (5초) | PC 크게 → 모바일로 전환 | "마감이 가장 먼저 보입니다" | |
| 3 | 역할별 칩 | — | — | — | 확인필요. 확인 전까지 영상에서 뺌 |
| 4 | 일정 타임라인 | 0:09–0:15 (6초) | PC(가로)와 모바일(세로)을 나란히 | "신청부터 동의까지 한눈에" | |
| 5 | 달력 신청 기간 | 0:15–0:19 (4초) | 모바일 가운데 | "신청 기간을 달력으로 확인" | |

| 11 | 마감 후 [종료] 전환 | — | — | — | 화면 없음. 영상에서 뺌 |

| 14 | 엔딩 | 0:42–0:45 (3초) | 로고 가운데, 배경 `--color-b-900` | "놓치지 않는 장학금 신청" | 화면 없음 → 로고만 떼어 새로 만듦 |

## 5. 화면 배치

| 배치 | 방법 |
|---|---|
| PC 화면 | 1280 × 863 프레임을 가로 1344px(1.05배)로 키워 가운데에 둔다. 라운드 `--radius-xl`(16px), 그림자 `--shadow-border` |
| 모바일 화면 | 360 × 843 프레임을 세로 900px로 키워 가운데에 둔다. 라운드 `--radius-2xl`(24px), 그림자 `--shadow-border` |
| 나란히 배치 | 왼쪽 PC(가로 1100px), 오른쪽 모바일(세로 760px). 사이 간격 80px |
| 기기 테두리 | 쓰지 않는다. 실제 기기 사진이나 다른 회사 기기 모양을 넣지 않는다 |
| 안전 영역 | 화면 가장자리에서 위아래 60px, 좌우 96px 안에 글자와 화면을 둔다 |

## 6. 움직임 규칙

### 속도 곡선 (easing)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 들어오기 | `cubic-bezier(0.22, 1, 0.36, 1)` | 카드, 화면, 글자가 나타날 때 |
| 나가기 | `cubic-bezier(0.64, 0, 0.78, 0)` | 사라질 때 |
| 이동 | `cubic-bezier(0.65, 0, 0.35, 1)` | 화면 전환, 탭 표시 이동, 스크롤 |
| 튕김 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | D-Day 배지, 완료 일러스트처럼 강조할 때만 |

### 시간

| 움직임 | 시간 |
|---|---|
| 버튼 눌림 | 0.15초 (크기 100% → 96% → 100%) |
| 글자, 배지 등장 | 0.4초 |
| 카드 등장 | 0.5초. 여러 개면 0.08초 간격으로 차례로 |
| 화면 전환 | 0.6초 |
| 선, 막대가 그려짐 (타임라인, 달력 기간) | 0.8초 |
| 장면 사이 | 새 장면이 들어오기 전 0.2초 겹치게 |

### 지킬 것
- 한 번에 하나만 크게 움직인다. 강조할 요소 하나를 정하고 나머지는 조용히 둔다.
- 튕김 곡선은 한 장면에 한 번만 쓴다.
- 화면이 빠르게 깜빡이는 효과(1초에 3번 넘게)는 쓰지 않는다.
- 화면 속 글자는 최소 1.5초 이상 멈춰서 읽을 시간을 준다.

## 7. 장면별 움직임

| 장면 | 움직임 | 분리 요소 (`아이디어.md` 3번) |
|---|---|---|
| 1 | 글자가 한 줄씩 아래에서 올라옴 → 마지막 단어 "마감 시각"만 `--color-point`로 바뀜 | — |
| 2 | 카드가 차례로 올라옴 → D-Day 배지가 튕기며 커짐(100% → 115% → 100%) | 장학금 카드 묶음, D-Day 배지 |
| 4 | 타임라인 선이 왼쪽→오른쪽(PC), 위→아래(모바일)로 그려지고, 점에 닿을 때 카드 등장 | 일정 요약 타임라인 |
| 5 | 신청 기간 강조 막대가 20일 → 24일로 채워짐 | 달력 |
| 7 | 탭 선택 표시가 다음 탭으로 미끄러지고, 내용은 옆으로 넘어감. 탭마다 1.2초 머무름 | 신청가이드 탭 목록 |
| 8 | 본문만 위로 스크롤되고 신청 버튼은 그대로 → 마지막에 버튼 눌림 | 하단 신청 버튼 |
| 9 | 다음 단계 버튼 눌림 → 화면 전환 → 단계바 점이 하나씩 채워짐 (1/4 → 4/4) | 진행 단계바, 다음 단계 버튼 |
| 10 | `소득인정액이란?` 버튼 눌림 → 어두운 배경이 깔리고 팝업 등장 → 확인 눌러 닫힘 | 소득인정액 안내 버튼, 팝업 |
| 13 | 완료 일러스트가 튕기며 커짐 | 완료 일러스트 |
| 14 | 로고가 가운데에서 서서히 나타나고 문장이 아래에 등장 | 로고 |

## 8. 확인필요

- 장면 3(역할별 칩), 6(최종 수정일): 화면에 해당 요소가 있는지 확인되면 영상에 넣는다. 넣으면 전체 길이가 약 8초 늘어난다.
- 장면 11, 12: 상태 화면을 새로 만들지 정해야 한다. 지금은 뺐다.
- 팝업이 바텀시트인지 가운데 창인지에 따라 장면 10의 등장 방향이 바뀐다. (바텀시트면 아래에서 올라옴, 가운데 창이면 가운데서 커짐)
- 배경음악과 효과음 출처.
- 영상을 만들 도구(Figma 모션, After Effects 등). 도구에 따라 속도 곡선 입력 방식이 다르다.
