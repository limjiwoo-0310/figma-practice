# 홍보 모션 영상 아이디어

- 기준 Figma
  - 모바일: `6. 모션` 페이지 › `장학금 서비스 화면_모바일` 섹션 (node `602:3360`)
  - 데스크탑(PC): `4. 완성화면` 페이지 › `장학금 서비스 화면_PC` 섹션 (node `213:12601`)
- 장면 구성은 `docs/PRD.md`의 핵심 사용자 여정(진입 → 정보 확인 → 과업 완수)을 따라 정했다.
- 피그마는 수정하지 않았다. 아래 내용은 화면을 읽기만 하고 정리한 것이다.
- 표시 규칙: **없음** = 장면에 맞는 화면이 없음 / **확인필요** = 화면만으로 판단하기 어려움

## 결정 사항

| 항목 | 결정 |
|---|---|
| 일정 값 | Figma의 자리표시 값(`0000.00.00`, `YYYY.MM.DD`) 대신 **예시 날짜**를 쓴다. 아래 '예시 날짜' 표를 따른다. |
| 데스크탑 화면 | 영상에 **넣는다.** 장면마다 모바일과 PC 화면을 함께 적었다. |

### 함께 확인할 점
- PC 화면은 `6. 모션` 페이지가 아니라 `4. 완성화면` 페이지에 있다. 모션 작업 때 PC 화면을 `6. 모션` 페이지로 복사할지 확인필요. (지금은 피그마를 수정하지 않았다.)
- 메인 세 번째 카드(국가근로장학금)의 배지가 모바일은 `D-0 00시 00분 마감`, PC는 `D-5 20시 00분 마감`으로 서로 다르다. 영상에서는 아래 예시 날짜에 맞춰 통일한다. 디자인을 고칠지는 확인필요.

## 2. 예시 날짜

> 모두 **영상용 예시 값**이다. 실제 장학금 일정이나 마감 시각이 아니다. 영상 화면 한쪽에 "예시 화면" 문구를 넣는 것을 권한다.
> Figma 달력(2026년 10월, 20~24일 강조)과 PRD의 예시 마감 시각(18:00)에 맞췄다.

| 항목 | 예시 값 | 쓰는 장면 |
|---|---|---|
| 영상 속 '오늘' | 2026.10.24 (토) | 2, 4, 8 |
| 국가장학금 1유형 신청 기간 | 2026.10.20 ~ 2026.10.24 | 2, 4, 5 |
| 국가장학금 1유형 마감 시각 | 마감 당일 18:00 → 배지 `D-DAY 18시 00분 마감` | 2, 4 |
| 국가장학금 2유형 마감 | 2026.11.07 18:00 → 배지 `D-14 18시 00분 마감` | 2 |
| 국가근로장학금 마감 | 2026.10.29 20:00 → 배지 `D-5 20시 00분 마감` | 2 |
| 서류제출 기간 | 2026.10.20 ~ 2026.11.03 | 4, 5 |
| 가구원 동의 기간 | 2026.10.20 ~ 2026.11.03 | 4, 5 |
| 최종 수정일 | 2026.10.15 | 6 (화면 확인 후) |
